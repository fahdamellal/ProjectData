# 📊 AI-Assisted Developer Performance Analysis

## 📖 Overview
This project is an academic data analysis and machine learning study that explores how **Artificial Intelligence tools** may influence **software developers’ performance**.

The objective is to analyze relationships between human factors (such as stress, sleep, and workload) and performance indicators, using Python-based data analysis techniques.

---

## 🎯 Project Goals
- Explore trends in developer performance data
- Analyze the impact of AI-assisted work
- Identify correlations between workload, stress, and success rate
- Apply basic machine learning models for performance prediction

---

## 🧰 Technologies Used
- **Python**
- **Pandas & NumPy** for data analysis
- **Matplotlib** for visualization
- **Scikit-learn** for machine learning
- **CSV datasets**

---

## 📊 Approach
The project follows a simple workflow:
1. Data exploration and cleaning  
2. Basic statistical analysis  
3. Correlation analysis and visualization  
4. Machine learning experimentation
